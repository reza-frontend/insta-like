# عکس محصولات

عکس هر محصول را با نام زیر در همین پوشه بگذارید (JPG، ترجیحاً مربعی با پس‌زمینه سفید، حدود ۸۰۰×۸۰۰). سایت خودکار آن را نمایش می‌دهد؛ اگر عکس نباشد آیکن برداری نشان داده می‌شود.

برای فرمت دیگر (png/webp) یا لینک اینترنتی، در `data/products.js` برای آن محصول `image: "..."` بگذارید.
