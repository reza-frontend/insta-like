# فروشگاه لوازم مصرفی پزشکی (قالب استاتیک)

سایت کاملاً استاتیک (HTML/CSS/JS خالص، بدون نیاز به سرور یا build). کافیست `index.html` را باز کنید یا پوشه را روی هر هاست آپلود کنید.

## صفحات
| فایل | توضیح |
|---|---|
| `index.html` | صفحه اصلی: هدر تیره، اسلایدر تمام‌عرض، کارت‌های دسته‌بندی، جدیدترین محصولات، پرفروش‌ها (BEST)، معرفی شرکت + ویدیو، برندها، مقالات، سفارش محصول / مشتریان |
| `shop.html` | فروشگاه با فیلتر دسته/برند/موجودی، جستجو (`?q=`) و مرتب‌سازی |
| `product.html?id=N` | صفحه محصول: گالری، مشخصات، تب‌ها، محصولات مرتبط |
| `cart.html` | سبد خرید/استعلام؛ ثبت سفارش فعلاً به واتساپ فروشگاه ارسال می‌شود |
| `about.html` / `contact.html` / `blog.html` | درباره ما + قوانین، تماس، مقالات |

## ویرایش
- **نام، تلفن، ایمیل، آدرس، واتساپ:** `data/site.js`
- **محصولات، دسته‌ها، برندها، مقالات، FAQ:** `data/products.js` و `data/site.js`
- **رنگ‌ها:** متغیرهای `:root` در ابتدای `assets/css/style.css`
- **عکس‌ها (لوگو، اسلایدر، دسته‌ها، محصولات، مقالات، ویدیو):** فقط فایل را با نام مشخص در `assets/img/` بگذارید — لیست کامل نام‌ها در `assets/img/README.md`.
- **بخش‌های صفحه اصلی (جدیدترین/پرفروش):** آرایه `HOME` در `data/products.js`
- **متن اسلایدر، سال تأسیس، لینک کاتالوگ، شبکه‌های اجتماعی:** `data/site.js`
- **قیمت:** `price: 0` یعنی «استعلام قیمت»؛ عدد تومان بگذارید تا قیمت نمایش داده شود.

## اتصال به بک‌اند
برای فروش آنلاین واقعی (درگاه پرداخت، پنل مدیریت) می‌توان همین قالب را روی ووکامرس/وردپرس یا هر بک‌اند دیگری پیاده کرد.
