# فروشگاه لوازم مصرفی پزشکی + پنل مدیریت

سایت فروشگاهی راست‌چین (فارسی) با پنل مدیریت. بخش عمومی سایت استاتیک و سریع است. پنل مدیریت با PHP نوشته شده و **به پایگاه داده نیاز ندارد** (داده‌ها در فایل ذخیره می‌شوند)، پس روی هر هاست اشتراکی معمولی (cPanel / DirectAdmin) اجرا می‌شود.

## نصب روی هاست
1. محتوای این پوشه را در `public_html` (یا یک زیرپوشه) آپلود کنید. نسخه PHP باید **۸.۱ یا بالاتر** باشد.
2. این پوشه‌ها باید قابل نوشتن باشند (دسترسی 755 یا 775): `data/`، `uploads/`، `admin/storage/` و همچنین فایل `data/content.js` (644 یا 664).
3. به آدرس `https://دامنه-شما/admin/` بروید. در اولین ورود، نام کاربری و رمز عبور مدیر را **خودتان می‌سازید** (رمز پیش‌فرض وجود ندارد).
4. در «تنظیمات سایت» نام، تلفن، آدرس، شبکه‌های اجتماعی و **آدرس سایت** را وارد کنید تا `sitemap.xml` و `robots.txt` خودکار ساخته شوند.

> روی سرور Nginx فایل‌های `.htaccess` اعمال نمی‌شوند. اطلاعات خصوصی همچنان محافظت می‌شوند (فایل‌های `admin/storage/*.json.php` از وب قابل خواندن نیستند)، ولی اجرای PHP در پوشه `uploads/` را در تنظیمات Nginx غیرفعال کنید.

## پنل مدیریت (`/admin/`)
| بخش | امکانات |
|---|---|
| داشبورد | آمار، آخرین سفارش‌ها، کارهای پیشنهادی |
| سفارش‌ها و پیام‌ها | سفارش‌های لیست استعلام و پیام‌های فرم تماس، وضعیت (جدید / در حال پیگیری / انجام شد)، یادداشت داخلی |
| محصولات | افزودن/ویرایش/حذف، تصویر، قیمت (۰ = استعلامی)، موجودی، مشخصات فنی، جدیدترین/پرفروش، جستجو و فیلتر |
| دسته‌بندی‌ها، برندها، مقالات، سوالات متداول | افزودن/ویرایش/حذف و تغییر ترتیب با کشیدن ردیف‌ها |
| تنظیمات سایت | اطلاعات تماس، درباره ما، مشتریان، کاتالوگ، ویدیو، شبکه‌های اجتماعی، اسلایدر صفحه اصلی |
| حساب و پشتیبان | تغییر رمز، دانلود و بازگردانی فایل پشتیبان |

**امنیت:** رمز عبور به صورت هش ذخیره می‌شود، بعد از ۵ تلاش ناموفق ورود به مدت ۱۵ دقیقه قفل می‌شود، همه درخواست‌ها توکن CSRF دارند، همه ورودی‌ها در سرور بررسی و خروجی‌ها escape می‌شوند، بارگذاری فقط تصویر واقعی (JPG/PNG/WEBP/GIF تا ۵ مگابایت) را قبول می‌کند، فرم‌های عمومی تله ربات و محدودیت ۵ درخواست در ۱۰ دقیقه دارند، و بعد از ۲ ساعت بیکاری خروج خودکار انجام می‌شود.

## ساختار
```
index.html, shop.html, product.html, cart.html, about.html, contact.html, blog.html, post.html, 404.html
data/content.js         ← همه محتوای سایت (پنل مدیریت آن را می‌نویسد)
assets/css/style.css    ← استایل؛ رنگ‌ها در :root
assets/js/app.js        ← هسته مشترک (هدر، فوتر، سبد، کارت‌ها، اسلایدر)
assets/js/icons.js      ← تصاویر برداری جایگزین
assets/js/pages/*.js    ← منطق هر صفحه
assets/fonts/           ← فونت وزیرمتن (روی سایت خودتان میزبانی می‌شود؛ مجوز OFL)
admin/                  ← پنل مدیریت (index.php، api.php، lib.php)
admin/storage/          ← سفارش‌ها و حساب مدیر (خصوصی)
api/order.php           ← دریافت سفارش و پیام از سایت
uploads/                ← تصاویر بارگذاری‌شده از پنل
```

## اجرای محلی
```bash
php -S localhost:8000
# سایت: http://localhost:8000   پنل: http://localhost:8000/admin/
```
اگر `index.html` را بدون سرور (دابل‌کلیک) باز کنید، سایت دیده می‌شود ولی پنل کار نمی‌کند و سفارش‌ها به واتساپ / ایمیل فرستاده می‌شوند.
